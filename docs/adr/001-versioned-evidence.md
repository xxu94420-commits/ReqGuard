# ADR 001：追加版本与证据快照

状态：采纳。

问题：覆盖原需求会使评分、反馈和交付证据失去上下文。决定：原文不可通过API修改；新文本追加Version；在事务内锁Requirement并校验baseVersion；数据库唯一约束(requirement_id,number)兜底。Feedback及报告仅追加。收益：可还原何时依据哪个版本作判断。代价：数据体积增加；删除与保留政策需后续实现。

记录采用固定关系字段＋JSON payload存派生结构，便于保留模型Schema快照；kind由业务服务固定，不开放任意记录写入接口。未来大规模分析可迁移到专用表/JSONB，不能因此更改旧评估。
